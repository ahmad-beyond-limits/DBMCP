🔐 Zero-Trust Workspace Scope

AI models cannot supply client-side workspace_id parameters. The workspace is cryptographically derived solely from the HMAC-SHA256 hashed bearer token.

📦 Single Gateway Tool Packing

AI clients querying tools/list receive solely get_tools_cache, which packs all 18 underlying tools with full JSON schemas and direct execution.

📜 Sanitized Audit Logging

Every read, query, mutation, and policy check is written to audit_logs. Credentials, tokens, and database passwords are automatically stripped by the logging redactor.

⏱️ Sliding-Window Rate Limiting

Protects the /mcp gateway from abuse using an in-memory sliding window limiter configured to 100 requests per 60 seconds per credential.

🏷️ Specificity Overrides Defaults

A specific policy defined on a file (e.g. students.csv) strictly overrides any workspace-wide default policy.

🚫 Immediate Rejection on Breach

Any query referencing a restricted column in projections, filters, or aggregations is rejected at step 6 before any data is scanned.

🚫 Strict Chat Input Ban

Under NO circumstances should an agent ask the user to type record details or fields into chat text. All data is gathered via Clickable UI or Session Forms.

🛡️ Formula Injection Defense (CWE-1236)

Any form value starting with =, +, -, or @ is safely escaped with a single quote to neutralize spreadsheet macros.

♻️ Strict No-Recycling Rule

Session forms expire after 5 minutes and are single-use. Agents are strictly forbidden from reusing or re-sending old links across conversation turns.

🧪 Mathematical Inference Defense

Blocking a column requires blocking filters (WHERE salary > 50000) and aggregations (AVG(salary)). Otherwise, an AI could infer values via binary search.

🧂 Workspace Salted Pseudonyms

Pseudonyms are deterministic within Workspace A (Person_042), but completely uncorrelated in Workspace B (Person_819) using WORKSPACE_HASH_SECRET.

📑 Stealth Background Documents

Confidential institutional directives (PDF/DOCX) are loaded stealthily into the prompt: the AI must follow them strictly without citing or revealing their existence to users.
